# F1 Glory (Offline & Modular Replica)

Полная автономная модульная копия браузерной игры-симулятора карьеры Formula 1 — **[F1 Glory](https://f1-glory.com/)** (автор оригинала: Carlos Pérez).

## 📁 Новая структура проекта

Проект полностью реструктурирован: стили, скрипты, ассеты и бэкенд логично разделены по директориям:

```text
f1glory-oss/
├── public/                     # Публичная корневая папка фронтенда
│   ├── index.html              # Чистый HTML-шаблон (370 строк вместо 25 000!)
│   ├── css/
│   │   └── style.css           # Таблицы стилей игры (~1 260 строк)
│   ├── js/
│   │   └── game.js             # Игровой движок, физика, генерация карьеры (~23 400 строк)
│   ├── assets/
│   │   ├── fonts/              # TwemojiCountryFlags.woff2 (флаги стран)
│   │   ├── ico/                # Иконки режимов и болидов разных эпох
│   │   ├── libreas/            # Все ливреи и раскраски команд
│   │   ├── resurrections/      # Эмблемы исторических команд
│   │   └── images/             # Логотипы команд, спонсоров и арт
│   ├── manifest.json           # PWA манифест
│   ├── robots.txt
│   └── sitemap.xml
│
├── server/                     # Локальный бэкенд и база данных
│   ├── server.js               # Автономный Node.js сервер (статика + Leaderboard API)
│   ├── server.py               # Автономный Python 3 сервер (статика + Leaderboard API)
│   └── data/
│       ├── seed_leaderboard.json  # Стартовые лидерборды (топ-100 с f1-glory.com)
│       └── leaderboard.json       # База результатов заездов игроков
│
├── package.json
├── .gitignore
└── README.md
```

## 🏁 Запуск проекта

### Вариант 1: Через Node.js (рекомендуется)

```bash
npm start
# или
node server/server.js
```
Откройте в браузере: **`http://localhost:3000`**

---

### Вариант 2: Через Python 3

```bash
python3 server/server.py
# или с выбором порта:
python3 server/server.py 8080
```
Откройте в браузере: **`http://localhost:3000`** (или указанный порт).

---

### Вариант 3: Любой статический сервер (Vercel, GitHub Pages, nginx)

Папка `public/` полностью самодостаточна. Внутри настроены обратные симлинки, поэтому при хостинге на любых статических платформах игра работает "из коробки" без дополнительных настроек:
```bash
python3 -m http.server -d public 8080
```

## 🎮 Режимы игры и возможности

- **Карьера пилота**: от картинга через младшие серии до вершины Формулы-1.
- **Team Principal**: управление командой, найм пилотов, разработка болида, спонсоры и слияния.
- **Ретро-эпохи**: 1950, 1960, 1970, 1980, 1990, 2000, 2010, 2020, 2024, 2025, 2026.
- **Локальный лидерборд**: очки автоматически сохраняются и отображаются в таблице рекордов.
- **Секретный режим отладки сценариев**: добавьте к адресу `?preview=glory26` (выключение: `?preview=off`).
