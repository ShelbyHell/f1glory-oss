# F1 Glory (Offline & Open Source Replica)

Полная автономная копия браузерной игры-симулятора карьеры Formula 1 — **[F1 Glory](https://f1-glory.com/)** (автор: Carlos Pérez).

## 🚀 Возможности копии

- **100% автономная работа**: все 380+ графических ассетов (болиды разных эпох, исторические и современные ливреи, логотипы команд, спонсоры, иконки, шрифт флагов `TwemojiCountryFlags.woff2`) сохранены локально.
- **Встроенный сервер с API лидербордов**:
  - `server.js` (Node.js без внешних зависимостей) и `server.py` (Python 3).
  - Поддержка эндпоинтов `/api/leaderboard`, `/api/submit`, `/api/me`.
  - Начальные лидерборды синхронизированы с оригинальным сайтом (`data/seed_leaderboard.json`).
  - Сохранение результатов локальных заездов в `data/leaderboard.json`.
- **Все режимы игры**:
  - Карьера гонщика (от картинга до F1).
  - Режим руководителя команды (*Team Principal*).
  - Ретро-эпохи (1950, 1960, 1970, 1980, 1990, 2000, 2010, 2020, 2024, 2025, 2026).
  - Еженедельные испытания и сценарные тесты (`?preview=glory26`).
  - Многоязычность (ES, EN, PT, PL, FR).

## 🏁 Быстрый старт

### Вариант 1: Запуск через Node.js (рекомендуется)

```bash
npm start
# или
node server.js
```
Откройте браузер по адресу: **http://localhost:3000**

---

### Вариант 2: Запуск через Python 3

```bash
python3 server.py
# или с выбором порта:
python3 server.py 8080
```
Откройте браузер по адресу: **http://localhost:3000** (или указанный порт).

---

### Вариант 3: Любой статический веб-сервер

Игра также может работать через любой статический веб-сервер (в этом случае лидерборд автоматически использует локальное хранилище `localStorage`):

```bash
python3 -m http.server 8080
```

## 📁 Структура проекта

```text
├── index.html                   # Основной движок игры, интерфейс и логика симуляции
├── server.js                    # Автономный Node.js сервер со статикой и API
├── server.py                    # Автономный Python 3 сервер со статикой и API
├── package.json                 # Скрипты запуска
├── data/
│   ├── seed_leaderboard.json    # Стартовые данные лидербордов (топ-100 по категориям)
│   └── leaderboard.json         # Локальная база результатов игроков
├── ico/                         # Иконки режимов и болидов разных эпох
├── libreas/                     # Ливреи и раскраски команд
├── resurrections/               # Возрожденные исторические команды
├── *.png / *.svg                # Логотипы конструкторов, спонсоров и фавиконы
├── TwemojiCountryFlags.woff2    # Локальный шрифт флагов стран
└── manifest.json                # PWA манифест для установки как мобильное веб-приложение
```

## 🛠️ Секретные режимы разработчика

Как и в оригинале:
- Активация режима тестирования сценариев: добавьте к URL `?preview=glory26`.
- Выключение режима превью: добавьте к URL `?preview=off`.
- Запуск конкретного теста: `?preview=glory26&test=<id>`.
